Template Syntax:
  Lines starting with '!!' are comments and will be filtered out.
  All leading and trailing newlines in the template will be trimmed.

  The only other characters with special meaning for templates are
    '{' and '}', which are used to insert parameters.
  There is no way to escape curly braces (make a PR if you
    really need them).

  Basic Parameters:
    A basic parameter is one that begins with any alphanumeric character,
      these parameters are the least configurable and not recommended.
  
  Canonical Parameters:
    Canonical parameters are prefixed with '='. They are guaranteed to be
      available and have consistent meanings.
    See `help templates canon-params` for a list of canonical parameters.
  
  Linked Parameters:
    Linked parameters are prefixed with '-'. They are defined by the
      'params.json' file in the template directory.
    See `help templates linked-defs` for information about defining
      linked parameters.
  
  Scraped Parameters:
    Scraped parameters are prefixed with '=!'. They are not currently
      implemented.
    See `help templates scraped-params` for details.
