This file documents the planned API for communicating with the scraper.

GET hostname/scrape?id={request wiki id}
RESPONSE:
{
    sitename<string>: the requested sitename
    domain<string>: the requested domain
    requester<string>: the user making the request
    private<boolean>: whether the request has the private box checked
    realperson<boolean>: whether the request has the real person box checked
    nsfw<boolean>: whether the request has the nsfw box checked
    body<string>: request body
    comments<Comment[]>: request comments
}

Comment:
{
    author<string>: who authored the comment
    date<string>: when the comment was authored
    body<string>: the content of the comment
}
